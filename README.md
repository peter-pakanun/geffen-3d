# Geffen: City of Magic — 3D Browser RPG

A 3D browser-based RPG inspired by **Geffen** (*Ragnarok Online*), built with Three.js and Web Audio.

## 🌐 Play Live
**[https://peter-pakanun.github.io/geffen-3d/](https://peter-pakanun.github.io/geffen-3d/)**

## ✨ Features
- **3D Circular Map of Geffen (`geffen.rsw`)**: Central Geffen Tower with levitating arcane rings, circular water moat, 4 cardinal stone bridges (N/S/E/W), outer cobblestone ring boulevard, Magic Academy, Blacksmith Forge, Apothecary, and 4 Town Gates.
- **Geffen Outskirts (`gef_fild00`) & Geffen Tower Dungeon B1 (`geffen_dun01`)**: Hunt Porings, Fabres, Poison Spores, Whispers, and the **Arch-Doppel [MVP]**.
- **Classic RO + Modern 3D Controls**:
  - **Left-Click Ground**: Click-to-move with tile indicator
  - **WASD / Arrow Keys**: Direct 3D movement
  - **Right-Click + Drag (or `Q`/`E`)**: Orbit camera 360°
  - **Mouse Wheel**: Zoom in/out
  - **Keys `1`–`6`**: Cast Fire Bolt, Cold Bolt, Jupitel Thunder, Meteor Storm, Arcane Sanctuary, and use Potions.
